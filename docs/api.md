# API

The Playwright-BDD API is organized into the following groups:

- [Configuration](api/configuration.md) — configure BDD projects and reporters.
- [Steps](api/steps.md) — create and define step functions and parameter types.
- [Hooks](api/hooks.md) — run code around steps, scenarios, and workers.
- [Decorators](api/decorators.md) — define fixtures and steps with decorators.
- [DataTable](api/data-table.md) — transform Gherkin data tables into arrays or objects.
